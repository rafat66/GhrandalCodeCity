## GhrandalCodeCity

GhrandalCodeCity is a standalone Java/Swing software visualization tool that represents object-oriented software systems as three-dimensional cities. It provides a visual environment for exploring software structure, metrics, and relationships through a consistent software-city metaphor.

The tool is designed for software comprehension, software architecture exploration, software visualization, and research involving object-oriented software systems.
