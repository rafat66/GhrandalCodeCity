## GhrandalCodeCity
A 3D Software City tool for analyzing and visualizing object-oriented source code, software metrics, and code relationships.

----

##Related Research

GhrandalCodeCity is associated with research on visualizing object-oriented software systems as three-dimensional cities.

Research topic:

Visualizing Object-Oriented Software Systems as 3D Cities
---
##Acknowledgment

GhrandalCodeCity was developed as a software visualization environment for representing object-oriented software systems using a three-dimensional city metaphor.

The project combines software structure, software metrics, and software relationships into an integrated visual representation intended to support software understanding and analysis.
